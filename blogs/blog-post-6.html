My AI Development Toolkit 2024

Essential tools and workflows that power my daily AI engineering work

Tools Productivity DevOps

Introduction

After years of building AI systems, I've refined my toolkit to maximize productivity. This post shares the essential tools I use daily, from development to deployment.

Development Environment

VS Code Extensions

Must-Have Extensions

  • Python: Core Python support
  • Pylance: Advanced IntelliSense
  • Jupyter: Notebook integration
  • GitHub Copilot: AI pair programming
  • Docker: Container management
  • GitLens: Advanced Git features

Essential Tools Summary

💡 My Complete Stack

  • Editor: VS Code with Python extensions
  • Environment: Poetry for dependencies, Conda for CUDA
  • Tracking: Weights & Biases for experiments
  • Version Control: Git + GitHub
  • Containers: Docker + Docker Compose
  • Cloud: AWS, Lambda Labs, RunPod
  • Code Quality: Black, isort, flake8, mypy
  • Documentation: Notion + Obsidian

Conclusion

The right toolkit makes all the difference. Start with the basics and gradually add tools as you encounter specific needs. The best toolkit is one you use consistently.
